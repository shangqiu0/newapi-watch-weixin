## v0.4.0 已实现内容

### 界面与交互
- 以原设计提示词为准，保留 `#237a73` 品牌色，使用亮白/暗黑两套 Token、系统字体与等宽读数；不加载 CDN 字体、脚本或图标。
- 248px 固定功能侧栏、64px 顶栏、独立平台选择、4 格发丝线 KPI；主用量折线/面积图与 1/3 状态区、细条排行构成主次层级。
- 登录、总览、渠道状态、告警、机器人与通知、模型服务、问答、审计均已改造。渠道支持已载入数据内的名称/ID 搜索和状态筛选，列表每页 20 条。
- 主题首屏在 CSS 前初始化，首次跟随系统；切换后本地持久化。移动导航为抽屉，背景 inert、焦点闭环、Escape 关闭并返回触发按钮。
- 实际图表只绘制已到达的时段，不把未来小时的空桶画成实测零值；保留数据覆盖说明、中文日期、主题驱动色、鼠标/键盘数据点信息。
- 单一互斥全局提示；模型另有连接诊断面板，未保存更改时禁用测试，测试与保存不会并发。更改模型配置使旧诊断失效，测试期间配置若变化则返回 409，不把旧结果标成新连接可用。
- 使用安全 DOM/textContent 构建界面，不使用 innerHTML 渲染模型或上游文本；注销清空工作区和配置表单，不把会话凭证放在 localStorage。

### 模型配置
统一使用 OpenAI Chat Completions。支持基础地址、`/v1` 基础地址或完整 `/chat/completions` 端点；完整端点不重复追加路径。Web 可选自动识别 / OpenAI 兼容 / DeepSeek 兼容；旧配置默认为自动，不需迁移或重填 Key。

官方 DeepSeek 端点自动关闭思考模式以匹配本项目强制工具调用工作流；通用接口不携带 DeepSeek 专有参数。保留真实工具证据校验、工具白名单与平台隔离，不用模型空答冒充取数成功。API Key 留空仍保留旧值。

### 真实验收发现并修复的状态误报
已保存 Webhook 的多平台实例，旧 Health 仍读取单服务 `.env` 的 webhook/bot 配置，造成 `notifications_unconfigured` 误报。现在 Fleet 给共享 Health 注入当前平台绑定与实际机器人认证快照；Web 与机器人健康查询使用同一个来源。Legacy `serve` 的默认行为保留。已覆盖启用/停用 Webhook、机器人认证/断开动态变化、平台停用场景。
