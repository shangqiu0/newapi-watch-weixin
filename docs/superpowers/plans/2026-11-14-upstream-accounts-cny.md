# 上游普通用户余额与人民币显示实现计划

日期：2026年11月14日。由当前会话原生执行，不启动子代理、不部署、不改真实凭证，不自动提交。

## 目标与边界

按监控平台保存独立的上游账户（地址、普通用户访问令牌、New-Api-User）。仅调用自身接口读取余额，独立阈值、恢复线、启停、轮询周期、查询机器人与通知目标。主平台管理员令牌保持原样。所有群成员权限一致，不建立网站多用户体系。

金额使用每个数据源自己的 quota_per_unit 与人民币显示汇率，后端Decimal换算，UI输入人民币，旧整数quota阈值不漂移。未确认参数显示未配置，不将未知数据当作零。渠道供应商balance不擅自套用quota公式。日报周报延期问题不处理。

## 结构和接口

- `money.py`：CurrencyConfig、状态接口候选参数、Decimal换算、白名单金额注解。
- `upstream_accounts.py` / `upstream_api.py`：账户DTO、加密配置存取、普通用户只读适配、隔离查询、余额状态/策略和认证/CSRF接口。
- 账户配置放在控制库既有加密平台JSON内；最近余额/错误及策略状态放在各平台既有meta/状态表，非原始业务日志仓库。
- `control_models.py`、`control_store.py`、`fleet.py`、`runtime.py`：兼容旧配置、配置验证、生命周期与取消、通知目标检查。
- `llm_tools.py`、`assistant.py`：仅暴露当前机器人被允许的上游账户，不让模型输入任意地址/令牌/平台ID；无模型时明确余额命令可用。
- 管理台新增上游账户页面和复用CurrencyEditor，主平台人民币设置、用户/额度/统计显示统一使用后端字符串；机器人主动通知使用显式接收会话。
