# 独立监控站 v0.5 本地开发设计

## 范围与决定
- 用户要求：完整平台数据、可编辑HTTP错误Webhook告警、逐用户余额阈值、日报周报开关、成熟框架前端、规范前后端结构；本轮不打发行包、不部署。
- 实现决定：保留 Python/FastAPI 后端；按最新用户文档，新增 pure-admin-thin + Vue3 + TypeScript + Vite + Element Plus + Pinia + ECharts 前端。前端按 app/api/components/features/utils 分层，后端新增 monitoring / query service / routes 模块，复用加密控制库与每平台数据隔离。
- 保持唯一管理账号和聊天用户一致权限；余额对象是绑定平台中的 NewAPI 用户ID，每个对象可独立阈值、启停、冷却与恢复通知。不是新增网站多用户。
- 方案比较：仅本地采集对历史不足；每问直读全量成本高；采用“查询按需向本平台管理接口完整分页读取 + 定时增量采集 + 已验证窗口缓存/明确来源”混合方案。不能越过上游授权与429，失败不冒充零数据。

## 已发现问题
- llm_tools.get_channels 固定 selected[:50]；工具需带全量汇总和可连续页明细，单渠道直接查询也走当前平台客户端。
- 首次日志仅24小时，本地0不能代表近7日上游0。统计查询对指定时间窗口分页取数后计算；失败明确上游错误，不假装完整。
- 当前真实一个平台接口429，另一个近7日有5条较早日志但本地0。只读诊断，不输出内容/凭证。
- 请求日志content/other原先全丢弃；本轮只提取脱敏HTTP状态/错误码/错误消息/渠道名，不存原始other、IP、token或请求内容。

## 后端契约
- 现有 /console/api Cookie/CSRF 登录继续使用；新router统一认证。
- /platforms/{id}/channels GET：live默认true，完整上游分页后返回本页、total、全量状态汇总、source/queried_at/complete。
- /platforms/{id}/statistics GET：日期<=31天、dimension/metric白名单、live默认true，返回全部汇总/排名/趋势、来源和覆盖。
- /platforms/{id}/logs GET：限定日期、分页、类型/渠道/status筛选，完整读取范围后在本地查询；失败502/503不返回空成功。
- /platforms/{id}/users GET：上游搜索脱敏DTO，返回明确分页。
- /platforms/{id}/monitoring GET/PUT：平台错误规则、用户余额规则、日报周报；PUT整份经校验、引用目标必须属于本平台，幂等保存。保存在既有加密平台config；runtime热加载定向生效。
- /platforms/{id}/alert-previews POST：只预览模板，不发消息。
- Webhook绑定可配置事件类别、text/markdown、@all。需要真正@所有人时使用企微text消息mentioned_list=['@all']，不是假造文字。
- 状态码支持自定义400..599列表、渠道/模型/错误码筛选、冷却聚合；同类错误按渠道/HTTP/错误码/模型聚合，重复日志去重、冷却后总结次数。状态码是日志实际上游HTTP错误，不是自己探测后臆测。
- 余额查询上游/api/user/{id}；quota原始单位显式标识，不冒充人民币，低于阈值/恢复分别持久化告警去重。
- 日报周报周期各自开关、时间、周几、可带图与通知目标；生成前补齐窗口；唯一outbox键防重启重复发。

## 数据与安全
- additive migration003：error明细列、查询覆盖窗口、错误去重/冷却bucket；每平台独立业务库，无跨平台SQL。
- 不在数据库事务中请求HTTP；全量读取失败不更新覆盖、截断必须显式。只对白名单字段输出、错误脱敏、不拼接模板代码。
- 测试修复先RED后GREEN；所有错误规则默认关闭，新增余额监控默认关闭，不发送真实群测试消息。

## UI方向
- 产品：多中转站运维值守工作站；性格：严谨、可读、专业；视觉：紧凑侧栏、宽工作区、表格与检查器。
- 使用Element Plus / PureTable组件而不是手写伪组件；中性表面、单强调色、数字tabular、无夸张卡片/光晕/渐变/emoji。
- 页面：运行概览、渠道、请求日志、用户额度、告警规则、余额监控、报告调度、连接与模型、数据问答、审计。
- 平台上下文常驻，时间中文，实时报错/空/加载区分；显示查询来源、范围、完整性；全部列表分页，支持筛选与明细抽屉。

## 执行与测试清单
1. client有效page_size小于请求时仍取完、工具>50条完整汇总、请求7天时向上游补数、不覆盖增量游标、429不伪造0。
2. 模板占位符注入拒绝、内容脱敏、HTTP码筛选、同日志去重、冷却计数与到时flush、不同平台不互发。
3. 两用户独立阈值/启停、恢复、失败不当0；日报周报启停/时区/重复tick/重启去重。
4. API认证/CSRF/平台404/无效输入/保存持久化；框架前端typecheck与组件/交互测试。
5. 本地开发服务器验收，不wheel/sdist/Docker发行构建、不公网部署；保持仅一个真实bot连接。真实接口限流如仍存在要明确保留问题，不能声称完整上游验收。

裁决：pureadmin文档覆盖React路线；保留旧API契约，监控功能新增router。只构建本地SPA，不wheel/Docker发布。无Git仓库，不伪造提交，不使用未授权子代理。
