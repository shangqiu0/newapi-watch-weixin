# NewAPI Watch 管理台 · Web 设计提示词 v1.1

> 使用方式：将下方提示词整体复制给任何 AI 编码工具（或作为设计规范交付给开发者）。
> 依据：ui-design / unslop / ui-ux-pro-max 三套设计体系 + 项目现有设计 Token（保留品牌色 #237a73）。
> 本文档只是设计规范提示词，不包含开发实现。
> **配套《前端框架选型-管理台.md》（v2 纯工程排序）**：推荐 vue-pure-admin thin / vben v5 / shadcn 系任一路线落地；本设计的 Token 为"主题目标值"，与具体框架组件库（Element Plus / shadcn）通过各框架的主题变量层对接，不绑定单一框架。

---

## 【设计方向】（先读这 5 行再动手）

- **产品**：面向个人运维者的 NewAPI 中转站监控管理台——看渠道健康、用量统计、告警与企微机器人状态。
- **性格**：安静、精确、可靠。像夜班仪器室里的一排仪表，不喧哗，读数一眼即中。
- **世界**：仪器与夜班。界面属于"值守"场景：用户会长时间盯着它，所以大面积必须是安静的中性灰阶，颜色只留给数据本身。
- **高光时刻**（全页仅此两处允许丰富）：① 主图表（渠道可用性/用量趋势，线条与面积用强调色精心绘制）；② KPI 大数字（等宽数字、干净利落）。
- **签名细节**：实时状态点——6px 圆点跟随采集状态变色（绿=正常/灰=停用/橙=降级/红=故障），全站统一，只有"采集中"那一颗允许极轻微的缓慢呼吸，其余全部静止。

---

## 【核心提示词正文】

为 NewAPI Watch（NewAPI 中转站监控管理台）设计并实现一套**极简、双主题（亮白/暗黑可切换）**的 Web 控制面板。界面为中文。所有颜色、字体、间距、圆角必须使用下方 CSS 变量 Token，禁止出现任何 Token 之外的硬编码值。

### 1. 主题系统（CSS 变量双套；`html[data-theme="light|dark"]` 或框架惯用的 `:root`/`.dark` 均可，Token 值不变，通过适配层映射到所用组件库的主题变量）

**亮白主题（默认）：**
```css
:root, [data-theme="light"] {
  --bg: #f6f7f7;            /* 页面背景，极浅灰（微带青调） */
  --surface: #ffffff;        /* 卡片/表格/表单容器 */
  --raised: #eef1f0;         /* 激活行、悬停底、输入框底 */
  --line: rgba(32,42,43,.08);   /* 发丝线：主文字色 8% 透明度 */
  --text: #202a2b;           /* 主文字 */
  --text-2: #5b6668;         /* 次级文字 */
  --muted: #727e80;          /* 辅助文字/图标 */
  --accent: #237a73;         /* 唯一强调色：品牌青绿 */
  --accent-soft: #edf5f3;    /* 强调色 8% 底（选中行/软底） */
  --ok: #16a34a;  --warn: #986c22;  --danger: #dc2626;
}
```

**暗黑主题（不是反色，是同结构的深灰阶梯，深度只来自"表面层级+发丝线"，禁止用阴影和发光）：**
```css
[data-theme="dark"] {
  --bg: #121514;             /* 页面背景 */
  --surface: #181d1c;        /* 卡片 */
  --raised: #232927;         /* 激活行/输入框 */
  --line: rgba(232,236,234,.08);
  --text: #e8ecea;
  --text-2: #9faba9;
  --muted: #7a8684;
  --accent: #4ab3a5;         /* 暗色下提亮的青绿，保证对比度 ≥4.5:1 */
  --accent-soft: rgba(74,179,165,.12);
  --ok: #4cc38a;  --warn: #d9a441;  --danger: #e5484d;
}
```

**主题切换**：顶栏放一个图标按钮（lucide 的 sun/moon，18px，描边 1.5）；点击切换 `data-theme`，写入 localStorage，首次访问跟随 `prefers-color-scheme`；切换时只过渡 `background-color / color / border-color` 160ms，无闪烁、无缩放动效。

**用色铁律**：功能色全站只有 4 个——强调青绿（操作/选中/链接）+ 绿（正常）+ 橙（降级）+ 红（故障/删除）。强调色覆盖面积 ≤5%（按钮/选中态/图表主线/一个关键数字）。禁止紫色（任何 #7xx/#6x6 系 hex）、禁止蓝紫渐变、禁止彩色阴影和发光描边、禁止大面积功能色打底。语义色必须同时有文字（状态词）不只靠颜色区分。

### 2. 字体（系统字体栈，禁用 CDN 字体——安全要求）

```css
--font-ui: -apple-system, "SF Pro Text", "Segoe UI", "PingFang SC",
           "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--font-num: "SF Mono", "Cascadia Mono", "JetBrains Mono", Consolas,
            ui-monospace, monospace;   /* 所有数字、ID、时间、耗时专用 */
```

字号阶梯（只用这几档，行高锁定）：

| 用途 | 字号/行高 | 字重 | 说明 |
|---|---|---|---|
| 页面标题 | 28px / 1.25 | 600 | letter-spacing -0.5px，全页仅一个 |
| 区块标题 | 18px / 1.4 | 500 | |
| 正文/导航/表格 | 14px / 1.6 | 400 | |
| 次级说明 | 13px / 1.6 | 400 | |
| 标签/元信息 | 12px / 1.5 | 400 | 禁止全大写+加宽字距 |
| KPI 大数字 | 30px / 1 | 500 | `font-variant-numeric: tabular-nums`，用 --font-num |

层级靠"字号+颜色深浅"区分，不靠加粗。小字（<16px）letter-spacing 一律 0。所有数字用等宽字体 + 千分位（`12,345`），同一页面数字格式统一。

### 3. 边距与栅格（4px 倍数，全站只有这一套间距）

```
间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48
```
- 控件内部：8–12；列表行间距：2–8；分组之间：12–24；区块之间：32–48
- **布局骨架**：左侧栏 248px（固定）+ 流式内容区，内容最大宽度 1440px 居中，页面左右留白 32px（≥1600px 屏 64px）
- 顶栏高 64px（含主题切换、平台状态、退出）；导航行高 36px、行距 4px，图标列对齐、文字单行
- KPI 条：4 格一行，格间用发丝线分隔（不用卡片框）；主图表区占内容宽 2/3、高 280–360px，右侧 1/3 放状态列表（不是第二张同尺寸图表）
- 卡片内边距 20–24px；表单 28–32px；弹窗 28px

### 4. 边框、圆角与深度

- **边框**：一律 1px 发丝线 `var(--line)`；输入框边框 1px，聚焦时边框变 `var(--accent)` + 外圈 3px `var(--accent-soft)`；分割线同 --line，永远不用深色分割线
- **圆角**（嵌套规则：内圆角 = 外圆角 − 间距，最小 4px）：
  - 小按钮/标签/状态点容器：6px
  - 按钮/输入框/表格行/导航行：8px
  - 卡片/图表块：12px
  - 弹窗/侧抽屉：16px
- **深度**：暗黑主题禁止阴影——用表面阶梯（surface/raised）+ 发丝线表达层级；亮白主题仅允许 `0 1px 2px rgba(0,0,0,.05)`（静置）与 `0 8px 24px rgba(0,0,0,.06)`（悬浮层如弹窗）；禁止发光、彩色投影、内彩虹描边

### 5. 组件规范

- **按钮**：高 40px（导航内 32px），左右 padding 16px。主按钮每区域最多 1 个（暗色主题下主按钮= 米白 `var(--text)` 底 + 深色字，比彩色块更克制；亮色主题= 青绿底白字）；次按钮= surface 底 + 发丝线；危险操作= 红色文字链接，不放红色大按钮
- **表格**：表头 12px 次级色、浅底 `var(--bg)`；行高 40–44px；数字列右对齐 + 等宽字体；hover 行 `var(--raised)`；操作列右侧固定，用文字链接；空表格显示"暂无数据 + 引导按钮"，不显示空框架
- **状态标识**：6px 圆点 + 文字（如 `● 正常`），点色 = 语义色，文字用 --text-2；这就是签名细节，全站复用同一组件
- **表单**：输入框高 42px，label 13px/500 在上方；错误信息红字 + `role="alert"`；禁用态 `--bg` 底 + `--muted` 字
- **弹窗**：右上角关闭（lucide x 图标），底部操作条右对齐，遮罩 `rgba(0,0,0,.3)`（暗黑 `rgba(0,0,0,.5)`）
- **状态完整性**：每个数据区域必须覆盖 加载骨架屏（16px 高 --raised 圆角条）、空态（居中浅灰图标+一句话+一个动作）、错误态（说明+重试按钮）、正常态，四态缺一不可

### 6. 图表（监控台的高光时刻，值得花心思）

- 主图表：**折线/面积图**（趋势数据），主线 `var(--accent)` 2px，面积填充强调色 12% 透明度；网格线 1px `var(--line)` 虚线；轴标签 12px `--muted` 等宽字体
- X 轴日期一律中文短格式 `M月D日`；tooltip 显示完整数据（中文时间 `YYYY年M月D日 HH:MM:SS`）
- 排行数据用"列表 + 细横条"（条宽=数值占比，强调色），不用饼图；同一页面最多一张大图表
- 图表颜色跟主题走（读 CSS 变量），暗黑下不加发光

### 7. 图标

统一 lucide 线性图标，16px 或 18px 二选一（全站统一），stroke 1.5px，颜色跟随所在文字角色（多为 --muted），图标到文字间距 8px，图标列纵向对齐。**严禁 emoji 做图标**，严禁混用填充/线性风格。无意义的装饰图标一律删掉。

### 8. 动效（一个缓动曲线，克制到底）

```css
--ease: cubic-bezier(0.22, 1, 0.36, 1);
```
- hover/按压/切换：120–180ms（只变 color/background/border-color）
- 菜单/弹窗/tooltip：160–220ms 淡入+上浮 6px
- 页面内容进入：300ms 淡入+上浮 8px，列表 stagger 40ms、最多 6 项
- 按压反馈：scale(0.98)；禁止 hover 放大卡片、禁止循环动画（唯一例外：采集中状态点的 2s 极轻透明度呼吸）、禁止 bounce
- 全站尊重 `prefers-reduced-motion: reduce`（关闭一切动画）

### 9. 文案规则（中文界面）

- 时间显示**只允许中文格式**：`2026年11月10日 14:30:05`（短格式 `11月10日`），严禁 ISO/纯数字/英文格式
- 标题命名上下文（如"渠道 · 今日"），不写"欢迎回来"；短文案结尾不加句号；不用感叹号；不用"强大/极速/智能"式空话
- 数据变化必须写明对比对象：`+12% 较昨日`；无法核实的数据不展示
- 空态文案具体可行动："还没有绑定告警群，去通知设置添加一个 Webhook"

### 10. 可访问性硬指标

- 正文对比度 ≥4.5:1（--text/--text-2 达标；--muted 只用于辅助小字）
- 键盘焦点可见：`outline: 3px solid` 强调色 40% 透明 + offset 3px
- 点击目标 ≥40px；所有交互元素 `cursor: pointer`
- 图片有 alt；错误用 `role="alert"` 播报

### 11. 响应式

- 断点：760px（移动）/ 1100px（窄桌面）/ 1600px（宽屏）
- 移动端：侧栏折叠为抽屉（汉堡按钮），KPI 2×2，主图表+列表纵向堆叠，字号不低于 12px
- 不出现横向滚动；表格在窄屏允许横向滚动容器

### 12. 禁止清单（负向约束，出现即返工）

❌ 紫色系任何色值 ❌ 蓝紫/彩虹渐变背景、渐变文字 ❌ emoji 图标 ❌ 彩色阴影、发光边框、玻璃拟态卡片 ❌ 循环播放的装饰动画 ❌ 全大写+宽字距标签 ❌ ISO 时间格式 ❌ 同页面两张同尺寸大图表 ❌ KPI 卡里塞迷你图/图标堆砌（KPI 卡=标签+大数字+对比小字，仅此三件） ❌ CDN 加载字体/脚本（安全要求，全部本地/系统资源） ❌ 纯色盲依赖（红绿必须配文字/形状）

## 【实现顺序建议】（交给 AI 工具时附上）

1. 按《前端框架选型-管理台.md》(v2) 选定技术路线（pure-admin thin / vben v5 / shadcn 系，风格靠主题适配层实现，不构成选型约束）
2. 先建 Token 层（上面两套 CSS 变量 + 主题切换逻辑；按所选组件库写一个 Token→组件库主题变量的适配层）
3. 再铺布局骨架（侧栏/顶栏/内容栅格）
4. 然后按 登录页 → 平台总览(KPI+主图表) → 渠道列表 → 告警 → 通知绑定 → 模型设置 → 问答工作区 逐页实现
5. 每页完成后对照第 12 条禁止清单自查一遍
